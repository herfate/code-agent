欢迎使用

本管理台用于本地调试 code-agent：左侧 对话演示 嵌入 /demo；开发 Agent 嵌入 /agent-dev 查询任务；父任务 嵌入 /dev-agent；用户配置 嵌入 /user-config 查询 system_config。

健康

启动后可通过 GET /health 检查服务与数据库。

会话

SQLite 持久化线程与消息；REST 见 /api/threads。

Agent
