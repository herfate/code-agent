核心特性

  • LLM Wiki 知识底座：AI 生成 + 人工补充双通道，沉淀代码规范、业务知识库与测试执行规范；开发设计消费代码规范/业务知识库，测试案例执行消费测试执行规范/业务知识库
  • 三重自愈循环：
    • 部署平台门禁失败 → 回退到代码开发节点（默认重试 3 次）
    • Code Review 失败 → 回退到代码开发节点（默认重试 3 次）
    • 测试案例执行失败 → 回退到代码开发节点（默认重试 3 次）
  • 全流程覆盖：从需求到上线的完整自动化流程
  • 多Agent协同：各环节由不同的 AI Agent 协作完成
