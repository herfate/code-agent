流程说明

完整闭环流程（自愈循环，默认3次）：

┌───────────────────────────────────────────────────────────────────────────────┐
│                                                                               │
│    开发设计 ──→ 测试设计 ──→ 代码开发 ──→ 部署平台发布                        │
│                               ↑                      │                        │
│                               │                      ↓                        │
│    测试案例执行 ──失败──┐   Code Review                              │
│         │               │          │                     │                  │
│         成功            │          └────── 失败重试 ──────┘                  │
│         ↓               │                                                     │
│    基线数据设计 ←── 测试案例设计 ←────────── 成功 ──────────┘                 │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘

核心特性

  • 双重自愈循环：
    • Code Review 失败 → 回退到代码开发节点
    • 测试案例执行失败 → 回退到代码开发节点（默认重试 3 次）
  • 全流程覆盖：从需求到上线的完整自动化流程
  • 多Agent协同：各环节由不同的 AI Agent 协作完成
